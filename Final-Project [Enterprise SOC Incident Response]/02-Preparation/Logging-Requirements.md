# Logging Requirements

## Windows Security Logs

| Event ID | Purpose |
|---|---|
| 4624 | Successful authentication |
| 4625 | Failed authentication |
| 4672 | Special privileges |
| 4688 | Process creation |
| 4698 | Scheduled task creation |

## Additional Telemetry

- PowerShell operational logs where available
- Sysmon process events where available
- IIS logs for the web-attack lab
- Endpoint file activity generated by the simulation

## Why These Logs Matter

The incident is reconstructed by combining multiple sources rather than relying on one event.

For example:

```text
4625 → 4624 → 4688 → PowerShell → Discovery
```

The exact sequence must always be verified against the actual timestamps in Splunk.

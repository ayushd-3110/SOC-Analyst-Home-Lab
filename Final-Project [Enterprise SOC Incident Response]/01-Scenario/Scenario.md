# Incident scenario

The exercise investigates a suspected authentication anomaly and subsequent Windows endpoint activity. The hypothesis was that failed logons preceded a matching successful logon, with later activity linked to the session. The archived evidence confirms a user network logon but does not establish the full failure-to-success or authentication-to-execution chain.

The purpose is to practice evidence-based triage, process review, investigation timelines, response reasoning and reporting. See the [evidence index](../Screenshots/README.md) and [final incident report](../16-Incident-Report/Final-Incident-Report.md) for observations and limits.

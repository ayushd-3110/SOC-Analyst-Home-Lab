# Objectives — Phishing Investigation

## Primary Objective

Investigate a simulated phishing email and determine whether suspicious activity can be identified and correlated through web-server and SIEM telemetry.

## Technical Objectives

1. Create a controlled phishing email sample.
2. Identify phishing indicators.
3. Analyze sender information.
4. Analyze suspicious URLs.
5. Generate controlled HTTP requests.
6. Investigate IIS logs.
7. Search IIS events in Splunk.
8. Identify source IP addresses.
9. Identify requested URL paths.
10. Analyze HTTP response codes.
11. Extract IOCs.
12. Create a phishing detection query.
13. Create a Splunk dashboard.
14. Map the activity to MITRE ATT&CK.
15. Produce an incident report.

## SOC Skills Practiced

- Email analysis
- Phishing investigation
- IOC extraction
- SIEM investigation
- Log analysis
- Web activity investigation
- Threat detection
- Incident documentation
- MITRE ATT&CK mapping

# Objectives

The objectives of this lab are:

- Understand IIS web server logging.
- Generate controlled web attack traffic.
- Detect SQL injection patterns.
- Detect path traversal patterns.
- Detect web enumeration.
- Search IIS logs using Splunk.
- Investigate suspicious source IPs.
- Correlate multiple web requests.
- Extract indicators of compromise.
- Build a security monitoring dashboard.
- Perform basic incident response.
- Map observed behavior to MITRE ATT&CK.

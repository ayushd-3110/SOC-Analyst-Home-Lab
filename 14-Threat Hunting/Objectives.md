# Objectives - Threat Hunting

## Primary Objectives

- Perform proactive threat hunting using Splunk.
- Develop and test a threat-hunting hypothesis.
- Analyze Windows process creation events.
- Investigate PowerShell execution.
- Identify Windows discovery activity.
- Analyze parent-child process relationships.
- Correlate authentication and process activity.
- Build an investigation timeline.
- Extract relevant indicators.
- Document the findings using SOC investigation methodology.

## Expected Learning Outcomes

After completing this lab, the analyst should understand the difference between:

Detection:

> Waiting for a known rule or alert.

Threat Hunting:

> Proactively searching available telemetry for suspicious behavior.

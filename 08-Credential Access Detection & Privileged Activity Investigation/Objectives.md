# Lab 8 — Credential Access / Mimikatz Detection

## Primary Objective

Detect and investigate suspicious credential-access activity associated with Mimikatz-like behavior using Windows Security logs and Splunk.

## Specific Objectives

By completing this lab, you should be able to:

1. Identify successful logon activity — Event ID 4624.

2. Identify privileged logon activity — Event ID 4672.

3. Investigate process creation — Event ID 4688.

4. Detect Mimikatz-related command-line indicators.

5. Correlate authentication and process activity.

6. Investigate the user, host, process and command line.

7. Extract relevant IOCs.

8. Map the activity to MITRE ATT&CK.

10. Determine whether the activity is suspicious or legitimate.

11. Document the incident like a SOC analyst.

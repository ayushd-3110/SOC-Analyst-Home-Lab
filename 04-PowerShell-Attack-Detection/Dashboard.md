# Dashboard Panels

Create the following panels in Splunk:

1. PowerShell Executions (Single Value)
2. ExecutionPolicy Bypass Events (Single Value)
3. Hidden PowerShell Events (Single Value)
4. PowerShell Timeline (Line Chart)
5. Top PowerShell Users (Bar Chart)
6. Top PowerShell Hosts (Bar Chart)
7. Suspicious Command Lines (Table)
8. Raw PowerShell Events (Table)

## Archived dashboard review

The panels use different scopes that have not been reconciled. ScriptBlockText is blank and the user is NOT_TRANSLATED. Event Code 1.png is a SecurityCenter Application event, not Sysmon process creation.

Treat the panel counts as historical search results, not confirmed incidents. Any proposed changes require a new Splunk run and screenshot; the original image has been preserved.

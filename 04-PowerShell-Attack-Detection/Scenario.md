# Business Scenario

ABC Technologies' SOC received an alert indicating suspicious PowerShell execution on a Windows workstation.

The command attempted to launch PowerShell with parameters commonly associated with malicious activity.

As a Tier-1 SOC Analyst, investigate the event and determine:

* Which host executed PowerShell?
* Which user launched the command?
* What command line was used?
* Was the activity malicious?
* What actions should be taken?

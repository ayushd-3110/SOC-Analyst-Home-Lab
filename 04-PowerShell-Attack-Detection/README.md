
## Overview

This lab demonstrates how a SOC Analyst detects suspicious PowerShell execution using Splunk Enterprise.

PowerShell is commonly abused by attackers for downloading payloads, executing scripts, bypassing defenses, and establishing persistence.

The lab simulates malicious PowerShell activity and investigates the resulting Windows and Sysmon events in Splunk.

## Skills Learned

* PowerShell Threat Detection
* Windows Event Analysis
* Sysmon Event Analysis
* Splunk SPL
* IOC Extraction
* Dashboard Development
* MITRE ATT&CK Mapping
* Incident Investigation

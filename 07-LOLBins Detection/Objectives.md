# Objectives

1. Understand Living-off-the-Land Binaries (LOLBins).
2. Understand why attackers abuse legitimate Windows binaries.
3. Generate controlled certutil.exe execution.
4. Generate Windows Security Event ID 4688.
5. Detect LOLBin execution using Splunk.
6. Extract process and command-line information.
7. Investigate user and host information.
8. Analyze parent-child process relationships.
9. Build Splunk detection queries.
10. Create a LOLBin monitoring dashboard.
11. Extract investigation artifacts.
12. Map the behavior to MITRE ATT&CK.
13. Produce a SOC incident report.
14. Document lessons learned.
